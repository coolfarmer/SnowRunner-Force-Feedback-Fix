# SnowRunner Force Feedback Fix

**English** · [Français](Readme_FR.md)

*A fix for abnormal steering wheel shaking when switching maps.*

## 🐛 The problem

When switching maps in SnowRunner, your steering wheel may suddenly start shaking rapidly and forcefully. This fix aims to prevent that behavior while preserving normal force feedback.

▶ **[Watch the bug on Reddit](https://www.reddit.com/r/snowrunner/comments/q109gb/i_have_successfully_captured_the_wheels_bug_shake/)**

## 📦 Installation

1. Close SnowRunner.
2. Download the fix's ZIP from the **[latest release](https://github.com/coolfarmer/SnowRunner-Force-Feedback-Fix/releases/latest)**, then extract it completely into a separate folder outside the game.
3. Open **`Install.cmd`**, select **English**, then **Install the fix**. Keep the `Sources` folder alongside `Install.cmd`.
4. Once installed, launch the game normally through **Steam**.

Use the compiled package: GitHub's **Code → Download ZIP** contains source code only.

**Updating:** uninstall the previous version first, with the game closed.

**Disable or uninstall:** close the game and reopen `Install.cmd` to access these options.

## 🎮 Compatibility

**Platform:** Windows 64-bit\
**Store:** Steam\
**Game Version/Build:** `1.907887.SNOW_DLC_19`

### 🛡️ Safe Activation

The fix only activates when a supported game version is detected. Unrecognized versions are left untouched, and console versions are not supported.

### 🕹️ Steering Wheel Support

The fix is designed to work with any steering wheel recognized by SnowRunner. However, **only the Logitech G923 has been tested**. Compatibility with other models has not yet been verified.
