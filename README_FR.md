# SnowRunner Force Feedback Fix

**Français** · [English](README.md)

*Un correctif pour les secousses anormales du volant lors des changements de carte.*

## 🐛 Le problème

Lors d'un changement de carte, le volant peut se mettre à osciller rapidement et fortement. Ce correctif vise à supprimer ce problème tout en conservant le retour de force normal.

▶ **[Voir la vidéo du problème sur Reddit](https://www.reddit.com/r/snowrunner/comments/q109gb/i_have_successfully_captured_the_wheels_bug_shake/)**

## 📦 Installation

1. Fermez SnowRunner.
2. Téléchargez le ZIP du correctif depuis la **[dernière release](https://github.com/coolfarmer/SnowRunner-Force-Feedback-Fix/releases/latest)**, puis extrayez-le entièrement dans un dossier séparé du jeu.
3. Ouvrez **`Install.cmd`**, choisissez **Français**, puis **Installer le correctif**. Gardez le dossier `Sources` à côté de `Install.cmd`.
4. Une fois l'installation terminée, lancez le jeu normalement depuis **Steam**.

Utilisez le paquet compilé : **Code → Download ZIP** sur GitHub contient uniquement les sources.

**Mise à jour :** désinstallez d'abord l'ancienne version, jeu fermé.
**Désactivation ou désinstallation :** fermez le jeu et rouvrez `Install.cmd` pour accéder aux options correspondantes.

## 🎮 Compatibilité

**Plateforme :** Windows 64 bits\
**Boutique :** Steam\
**Version/Build du jeu :** `1.907887.SNOW_DLC_19`

### 🛡️ Activation sécurisée

Le correctif s'active uniquement lorsqu'une version compatible du jeu est détectée. Les versions non reconnues restent inchangées, et les versions console ne sont pas prises en charge.

### 🕹️ Prise en charge des volants

Le correctif est conçu pour fonctionner avec tout volant reconnu par SnowRunner. Cependant, **seul le Logitech G923 a été testé**. La compatibilité avec les autres modèles n'a pas encore été vérifiée.
